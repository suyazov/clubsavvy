# ClubSavvy / clubsavvy.shop — решения

## Решение 1. Этап 1 выполняется в сокращённом объёме

Дата фиксации: 01.07.2026.

Этап 1 выполняется за 3 000 ₽ как сокращённая чистка витрины.

В этот объём входит только самое критичное:

- убрать лишние пункты меню;
- убрать ненужные демо-страницы и разделы;
- почистить демо-информацию;
- убрать ненужные статьи вроде «Обзор авто»;
- заменить информацию о компании временным или предоставленным текстом;
- базово поправить явные визуальные ошибки каталога;
- проверить, что основные страницы открываются нормально.

## Решение 2. Полное ТЗ не входит в 3 000 ₽

В 3 000 ₽ не входят:

- полная переработка «Как оформить заказ»;
- пошаговая инструкция на главную;
- подготовка и аккуратная замена всех изображений категорий;
- глубокая доработка SPro;
- логика баланса;
- QR-пополнение;
- списание с баланса;
- синхронизация с сайтом кооператива.

Эти задачи выносятся в отдельную оценку.

## Решение 3. Текст «О компании» временно можно сделать шаблонным

Клиент разрешил временно вставить нейтральный шаблонный текст в раздел «О компании».

Финальный текст можно заменить позже, когда клиент предоставит точное описание, реквизиты или позиционирование.

## Решение 4. Картинки категорий должен прислать клиент

Клиент сообщил, что изображения для категорий у него есть.

Статус: ждём изображения.

Если изображения готовы и легко заменяются через админку, можно поставить их в рамках текущей чистки. Если потребуется обработка, подбор, генерация или ручная подготовка — это отдельная оценка.

## Решение 5. Сначала работаем через админку Bitrix

Клиент сообщил, что хостинг/SSH пока, возможно, не нужен.

Сначала правки выполняются через админку Bitrix.

Если через админку не получится внести нужные изменения, запрашивается доступ к хостингу или файлам проекта.

## Решение 6. Этап 2 по балансу оценивается после технического изучения

Предварительная оценка этапа 2: от 16 000 ₽.

Финальная стоимость подтверждается только после изучения:

- Bitrix / SPro;
- корзины;
- оформления заказа;
- пользователей;
- личного кабинета;
- текущей системы баланса;
- сайта кооператива;
- доступного API или базы данных.

## Решение 7. Секреты не хранятся в GitHub и AFFiNE

В GitHub и AFFiNE не хранить:

- пароли;
- токены;
- SSH-ключи;
- платёжные данные;
- приватные URL с авторизацией;
- персональные данные пользователей.

Допускается хранить только карту доступов: какой доступ есть, когда получен, где хранится исходная информация.

## Аварийное исправление 2026-07-02
- При аварийной жалобе клиента сначала проверять HTTP-статус публичной страницы и доступность админки.
- Для Aspro Max menu-файлы нужно записывать только через heredoc или другой способ, который гарантирует реальные переносы строк, а не буквальные `\n`.
- После правки активных menu-файлов обязательно делать один smoke-test главной страницы.
